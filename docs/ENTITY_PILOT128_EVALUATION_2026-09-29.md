# 128 局教师数据与 PPO 模型的独立评测

评测对象：`reports/entity-pilot128-v2-repaired/entity-ppo.pt`，两套牌为龙战和快攻德。模型输入是可见实体状态，评测采用策略网络的合法动作 argmax；未叠加搜索，留牌沿用引擎默认行为。对局 seed `202610010000` 起，与训练及此前开发、确认 seed 分离。每种有序卡组配对 16 个 seed，每个 seed 交换候选模型座位，共 128 局。每局上限 400 个动作或 120 秒，失败和截断单独统计。

| 对手 | 胜 | 负 | 完成/计划 | 64 对座位交换 seed 的保守 95% 区间 |
| --- | ---: | ---: | ---: | ---: |
| 128 局教师数据的 bootstrap 最佳 checkpoint | 76 | 52 | 128/128 | 42.40%–76.35% |
| 旧 `closed-loop-v2.epoch2.pt` 模型 | 91 | 37 | 128/128 | 54.12%–88.07% |

两组均为 0 失败、0 截断和 0 非法动作。与 bootstrap 对照的胜率为 59.38%，64 对中候选两胜 24 对、各胜一局 28 对、两负 12 对；对非平局配对做双侧符号检验，`p≈0.0653`。因此此次样本只能说有提升迹象，未达到这个检验的 0.05 门槛。对旧模型的胜率为 71.09%；相应配对数为 35、21、8，双侧符号检验 `p≈0.00004`。这些是本模拟器、两套牌和纯策略推理下的结果，不能外推为真实天梯胜率。

| 候选卡组 / 对手卡组 | 对 bootstrap | 对旧模型 |
| --- | ---: | ---: |
| 快攻德 / 快攻德 | 20–12 | 27–5 |
| 快攻德 / 龙战 | 8–24 | 11–21 |
| 龙战 / 快攻德 | 27–5 | 32–0 |
| 龙战 / 龙战 | 21–11 | 21–11 |

另用 8 个固定合成根局面做纯策略检查：最终 PPO、bootstrap 均答对 **4/8**；旧模型答对 **8/8**。PPO 能完成即时斩杀、已生成火球斩杀、低费可打随从以及保命叠甲；仍错过先获取随机信息、防止对手场攻斩杀、留费用于本回合斩杀、通过交换触发阈值收益。这些用例是诊断集，部分曾用于旧模型开发，不作为独立强度证明；它们清楚显示当前 PPO 的多步战术没有随着整体胜率同步改善。

额外试验将实体模型作为 ISMCTS 策略先验，2 个隐藏状态采样 × 32 次搜索，深度 3 的启发式 rollout，不使用其 value head，也不启用战术预检：答对 **5/8**。阈值触发的交换得到修正；先生成信息、防止对手场攻斩杀、留费本回合斩杀仍失败。该结果说明已有搜索能补回一部分局面，但此预算下不足以修复全部多步规划失误。记录在 `reports/entity-selfplay-v1-20260929/entity-pilot128-tactical-search-prior-only.json`。

结论：保留最终 checkpoint 作为研究候选，不替换实时建议模型。下一轮应在独立战术局面上增加反事实续着评估与动作结果监督，同时保留座位配对的独立对战；继续重复同一批 PPO 对局或只加 epoch 缺少解决上述失误的证据。
